# Arquitectura de SecureBank API

## Capas principales

### Presentación
Endpoints de la API.

### Lógica de negocio
Procesamiento de autenticación,
cuentas y transferencias.

### Datos
Persistencia de usuarios,
cuentas y movimientos.

## Seguridad

La arquitectura considera:

- autenticación
- autorización
- validación de entradas
- auditoría
- protección de secretos
- controles DevSecOps
